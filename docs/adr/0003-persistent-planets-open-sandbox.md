# ADR-0003：以持久星球和自由往返为核心

- 状态：已接受
- 日期：2026-08-17
- 取代：[ADR-0002](0002-expedition-centered-gameplay-loop.md)

## 背景

早期设计将“搜打撤”理解为星球活动的统一结构：选择目标、进入地表、取得物品并通过撤离完成结算。这种结构适合短时任务和敌对突袭，却会把星球变成只有任务才进入、任务完成才离开的副本。

项目的真实目标是开放沙盒宇宙。星球、小行星、空间站、飞船和基地都应是持续存在、可自由往返的地点。玩家可以无任务探索、长期停留、生活和建设。

## 决策

星球采用持久地点模型：

- 登陆不需要任务；
- 离开不需要完成目标；
- 玩家可以自由决定停留时间；
- 星球在玩家离开后保留物品、NPC、设施、势力与环境变化；
- 任务是世界中的机会，不是进入和离开的控制器；
- 不设置适用于所有星球的统一压力计时；
- 氧气、天气、敌人和增援只在相应环境或行为下产生压力；
- 物品取得后即属于玩家，储存位置决定其安全程度；
- 搜打撤只作为突袭、潜入和危险争夺等特定情境下的自然体验。

飞船是玩家的移动家园，地面基地是可选的长期据点，两者与星球共同组成连续世界。

## 结果

### 正面影响

- 支持自由探索、长期驻留和基地建设；
- 和平生活、贸易、招募与敌对行动可以发生在同一星球；
- 玩家行为能够留下持久痕迹；
- 搜打撤、任务和生存压力可以按情境出现，不会支配全部玩法；
- 飞船更接近“家”，而不是副本大厅。

### 代价

- 需要保存星球和地点的长期状态；
- 不能依赖任务流程自动清理场景与对象；
- 内容设计必须让自由探索本身具有地点差异和意义；
- NPC、势力、物品和设施的跨时间变化更复杂；
- 需要谨慎控制生存机制，避免重新形成统一倒计时。

## 被否决的方案

### 所有星球采用搜打撤循环

能够快速形成紧张和结算感，但会把开放星球变成重复进入的任务副本。

### 只有接受任务后才能登陆

易于控制内容与流程，但不支持无目的探索、生活和玩家自主目标。

### 任务完成后自动撤离或结算

流程清晰，但破坏地点连续性，也削弱长期驻留和建设玩法。

### 所有地表活动共享统一压力计时

容易制造紧迫感，但会让和平星球、基地生活和普通探索都变成被催促的短局游戏。
