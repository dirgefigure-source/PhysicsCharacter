# ADR-0002：以撤离为结算边界的远征核心循环

- 状态：已被 ADR-0003 取代
- 日期：2026-08-17

> 本决策曾把搜打撤式远征提升为全局核心循环。后续设计确认星球应是可自由往返的持久地点，撤离不应成为统一结算边界。当前决策见 [ADR-0003](0003-persistent-planets-open-sandbox.md)。

## 背景

游戏需要连接飞船经营、星球地表行动、资源建设和势力政治。若采用“采集资源后直接兑换金钱”的任务循环，资源、飞船与宇宙状态之间缺少长期联系，也难以形成搜打撤体验。

## 决策

采用以星球远征为中心的三层结构：宇宙战略层、星球远征层、飞船与基地层。

地面获得的资源、装备、人员和情报在成功撤离前视为临时持有；撤离后才进入玩家的持久资产。任务完成与远征结束相互独立，玩家可以提前撤离、继续深入或改变目标。

人员、物资、情报、暴露度、时间和撤离能力必须跨阶段持续，并在远征结束后改变飞船与宇宙状态。

## 结果

### 正面影响

- 准备、探索、贪婪和撤离形成统一决策链；
- 资源直接服务于飞船、制造、研究和基地建设；
- 失败可以产生营救、追踪和报复等后续内容；
- 和平访问、秘密行动与武装突袭可以共用星球框架；
- 飞船经营与势力政治获得稳定的内容来源。

### 代价

- 必须保存跨场景的远征状态；
- 撤离、伤员、遗失物和局势后果增加系统复杂度；
- 任务不能只用简单的完成/失败布尔值表示；
- 需要控制惩罚强度，避免玩家因损失过大而依赖读档。

## 被否决的方案

### 资源直接兑换金钱

实现简单，但容易形成重复刷取，削弱资源种类、飞船建设与远征后果。

### 完成任务后自动结算并离开

流程明确，但移除了主动撤离、继续深入和临时改变目标的核心张力。

### 每颗星球作为独立无持久后果副本

便于重复游玩，但不能支撑势力扩张、基地建设和动态宇宙。
